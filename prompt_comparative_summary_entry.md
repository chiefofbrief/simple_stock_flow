# Prompt: Comparative Summary Entry

**Task:** Write the per-company entry for `Data/comparative/Comparative_Summary_AI.md` for the ticker specified by the user.

---

## What to read

1. `GEMINI.md` — read this first.
2. The company's full section in `Data/comparative/Comparative_Analysis.md` — every line. This is the only source. Do not read ticker files.

---

## What to write

Four sections, followed by ratings and expected value. Use the NVDA entry in `Data/comparative/Comparative_Summary_AI.md` as the format reference.

- **Business Quality**
- **Valuation**
- **Narrative**
- **Catalyst — next 3 months**

Then ratings:

```
Quality: X | Valuation: X | Narrative: X | Catalyst: X
```

Then expected value:

**Expected value: [a dollar for X cents / a dollar for X dollars]**

---

## After writing

Add the entry to `Data/comparative/Comparative_Summary_AI.md` below the existing entries. Update the summary table at the top with the company's ratings and expected value.
